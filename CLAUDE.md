# tinycloud-platform

Go platform API and coordinator, with a Vite/TypeScript UI under `ui/`. Deployed from the `gitops-lab` repo.

## Agent skills

### Issue tracker

Issues live as GitHub issues on `sasiruLK/tinycloud-platform`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, using the default label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
